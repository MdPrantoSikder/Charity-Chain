ℹ️ CB-BFT Layer Descriptions
L1 — Entry Gate: Validates stake ≥ 0.5 and reputation ≥ 0.35. Rejects nodes below threshold.
L2 — F-Score Calculation: Combines reputation, uptime, latency, bandwidth, and stake with weighted entropy and variance (α=0.6, β=0.4).
L3 — Temporal Decay: Applies exponential decay to reputation and uptime scores based on time since last activity.
L4 — Normalization: Min-max normalization across all nodes to ensure fair comparison.
L5 — SGDC Pool Formation: Score-Guided Density Clustering assigns nodes to Elite / Standard / Observer / Probation pools with Gini diversity check.
L6 — VRF-WRLE Leader Election: Verifiable Random Function with Weighted Random Leader Election picks leader from Elite pool.
L7 — Intra-Pool BFT: Byzantine Fault Tolerant consensus within each pool (2f+1 votes required).
L8 — Inter-Pool HotStuff: HotStuff protocol synchronizes decisions across Elite and Standard pools.
L9 — JSD Drift Monitor: Jensen-Shannon Divergence monitoring — triggers recluster if JSD > 0.15.
