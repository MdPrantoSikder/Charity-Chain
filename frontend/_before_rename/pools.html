ℹ️ About ABPC Pool Assignment

ABPC L5 — SGDC Pool Formation: Nodes are assigned to pools based on their F-Score, which combines reputation, uptime, latency, bandwidth, and stake. The Score-Guided Density Clustering (SGDC) algorithm ensures:

  • Organization diversity (Gini coefficient ≤ 0.35 per pool)
  • Minimum pool size enforcement (≥ 3 nodes per pool)
  • Reputation floor (< 0.35 → automatic Probation assignment)
  • Dynamic reclustering when L9 detects JSD drift > 0.15

Elite Pool handles primary consensus (L6 VRF-WRLE, L7 BFT, L8 HotStuff). Standard Pool serves as backup. Observer Pool monitors but doesn't vote. Probation Pool is for low-reputation nodes under review.
